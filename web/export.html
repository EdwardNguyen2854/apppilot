Export Format

Exported ZIP files contain:

  • summary.json — Export metadata and statistics
  • sessions.csv — App session records
  • events.csv — Usage events
  • health_checks.csv — Health check results
  • process_metrics.csv — CPU/RAM metrics

All timestamps in ISO 8601. Machine ID and user alias included.
